# STD-REPO-001 · Repository file structure

## 1. Purpose

Ensure that every repository in the organization contains a complete set of metadata files that help new contributors understand the project, license the code, and maintain the change history.

## 2. Scope

Applies to all code or documentation repositories managed in the `dev.rachuna` group. It does not apply to archived repositories (`archived: true`).

## 3. Requirements *(normative)*

- **R1.** The repository MUST contain a `README.md` file in the root directory.
- **R2.** The repository MUST contain a `CODEOWNERS` file defining owners for code areas.
- **R3.** The repository MUST contain a `CHANGELOG.md` file generated automatically by semantic-release from commits (STD-REPO-003).
- **R4.** The repository MUST contain a `LICENSE` file defining the license terms.
- **R5.** The repository MUST contain a `CONTRIBUTING.md` file describing how to contribute.
- **R6.** The repository MUST contain a `CODE_OF_CONDUCT.md` file defining collaboration rules.
- **R7.** The repository MUST contain a `.gitlab/footer.md` file, the GitLab interface footer.
- **R8.** The repository MUST contain a `.gitlab/badges.md` file, the badges displayed in the README.
- **R9.** The repository MUST contain a `.gitlab/avatar.png` file, the project avatar.
- **R10.** The repository MUST contain a `.gitignore` file.

## 5. Implementation — good practice *(informational, non-binding)*

- **README.md** — project description, quickstart, links to documentation.
- **CODEOWNERS** — mapping of paths to teams; each MR gets automatic reviewers.
- **CHANGELOG.md** — generated by semantic-release for each tag; do not edit manually. Details: STD-PROC-004.
- **LICENSE** — for internal repositories: the organization's own license or CC BY-NC-SA 4.0.
- **CONTRIBUTING.md** — how to report bugs, how to create MRs, commit standards (link to STD-PROC-003).
- **CODE_OF_CONDUCT.md** — recommended [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
- **`.gitlab/`** — GitLab interface configuration files; copy them from the discipline repository (STD-PROC-006).
